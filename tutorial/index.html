Automatisez vos workflows,
sans écrire une ligne.

Autome est une plateforme d'automatisation type Make / n8n / Zapier : vous dessinez un graphe de nodes (déclencheurs, actions, logique), et un moteur fiable l'exécute à votre place. Ce guide se parcourt page par page — avec un éditeur jouable.
