06 — Démarrer en local

Tout lancer en une commande

La stack complète (DB, queue, services, monitoring) tourne en conteneurs.

# Option A — tout en conteneurs (recommandé)
# pré-requis : Docker + Docker Compose
docker compose up --build
ServiceURLNotes
APIlocalhost:8080GET /health, GET /metrics
Frontendlocalhost:8081SPA — l'éditeur visuel
Grafanalocalhost:3000admin / admin
Prometheuslocalhost:9090scrape de l'API
RabbitMQlocalhost:15672UI management — guest / guest
Profil dev avec des secrets de développement — ne pas utiliser tel quel en production. Arrêt + nettoyage des volumes : docker compose down -v.
# Option B — développement local (Rust ≥ 1.85, Node ≥ 20, PostgreSQL)
# 1. configuration
cp .env.example .env

# 2. API HTTP
cargo run -p autome-api        # 127.0.0.1:8080

# 3. worker (exécuteur de runs)
cargo run -p autome-worker

# 4. frontend
cd frontend && npm install && npm run dev

Un workflow, c'est juste du JSON

Exemple Slack → Gmail → Notion (extrait de examples/workflows/).

{
  "name": "Slack → Gmail → Notion",
  "nodes": [
    { "id": "entry",      "kind": "trigger", "trigger_type": "manual" },
    { "id": "slack_read", "kind": "action",  "action_type": "slack.read_channel" },
    { "id": "gmail_send", "kind": "action",  "action_type": "gmail.send_email",
      "params": { "body": "Dernier message : {{ slack_read.messages.0.text }}" } }
  ],
  "edges": [
    { "from": "entry",      "to": "slack_read" },
    { "from": "slack_read", "to": "gmail_send" }
  ]
}
